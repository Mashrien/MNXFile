# MNXFile 1.2.0-alpha.3 — initial public prerelease

Downloads: Linux RPM/DEB/tar, Windows ZIP, and `Mash.MNXFile` /
`Mash.MNXFile.Client` NuGet packages. The NuGet packages are GitHub downloads;
this version has not been uploaded to NuGet.org. Managed NuGet consumers target
.NET10; the native runtime packages need no installed framework.

The engine supports streaming archives, a front index, Unicode names, None/Brotli/
LZ4/Snappy compression, AES-256-GCM, verification, tail compaction, and controlled
cancellation/resume queues. Optional queue key exports are convenience material;
read MNQ_FORMAT.md before enabling them.

Install the `mnxfile` RPM/DEB first, or extract the portable archive and set
`MNXFILE_NATIVE_LIBRARY` to its absolute library path. On Windows run the ZIP's
`install-runtime.ps1` to install per user. The Windows ZIP supplies the native C
header and import library; the Linux portable bundle supplies the C header.

## Purpose and package layout

MNX was created for very large network archives and NAS backups. Its complete
front index supports inexpensive browsing/search, and payloads stream through
bounded buffers rather than loading an archive into memory.

The engine is independently installed. Install MNXFile before the CLI or GUI;
neither interface contains a private engine. Native ABI 1/application protocol 1.
This is the first public prerelease. Disk schema MNX7 does not support old MSX
prototypes. Controlled cancel/resume is not a power-loss journal.

## Platforms

- Linux x86-64: NativeAOT, built on Ubuntu24.04; requires glibc2.39+ and OpenSSL3.
- Windows10 x64: native engine and both CLIs use AOT. WinForms GUI is self-contained
  single-file, not AOT. No installed .NET runtime is required by these binaries.
- Native payloads use .NET runtime/ILCompiler10.0.14. Linux SDK10.0.403;
  Windows SDK10.0.402. ARM64 releases are not supplied.
- SHA256SUMS covers the release downloads. Packages are unsigned; use the published
  hashes to check download integrity.

## Validation

Engine, managed client, native C ABI and codec/encryption smoke checks passed on
Linux x64 and Windows10 x64. Windows link fixtures were tested with the required
elevated symlink privilege.
